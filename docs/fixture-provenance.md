# Fixture provenance

No workflow JSON fixtures exist at the T11 audit commit. The
`@flowdiff/test-fixtures` package is currently a package shell.

T03 and every later fixture contribution must update this file with fixture
names and authorship. Accepted fixtures must be original synthetic workflows,
contain no real workflow/customer data, hosts, credentials, tokens, or secrets,
and must not copy n8n proprietary or Enterprise implementation or fixtures.
Public n8n workflow JSON structure may be used solely as an interoperability
format.
