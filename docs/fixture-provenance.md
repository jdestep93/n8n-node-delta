# Fixture provenance

All workflow JSON fixtures in `@flowdiff/test-fixtures` are original synthetic
workflows created for FlowDiff. They are generated by
`packages/test-fixtures/scripts/generate-fixtures.mjs` (run with
`pnpm --filter @flowdiff/test-fixtures generate`), authored by the FlowDiff
maintainers for ticket T03, and contain no real workflow, customer, host,
credential, token, or secret data. Example URLs use reserved
`.example.invalid` hosts, and node types reference public n8n node type names
solely as the interoperability format. No n8n proprietary or Enterprise
implementation or fixtures were copied.

Current fixture corpus (eleven original before/after pairs, 22 JSON files):

- `simple-before/after` — metadata-only change pair (hash stays stable);
- `node-added-before/after` and `node-removed-before/after`;
- `node-modified-before/after` — parameter, expression, credential, and
  community-node metadata coverage;
- `node-renamed-before/after` and `node-moved-before/after`;
- `connections-before/after` — output/input types and indexes;
- `code-before/after` and `sql-before/after`;
- `ai-prompt-before/after`;
- `large-workflow-before/after` — 300 nodes per side for performance.

Later fixture contributions must regenerate or hand-extend with the same
constraints and record any new names here. Public n8n workflow JSON structure
may be used solely as an interoperability format.
